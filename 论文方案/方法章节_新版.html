3 方法

3.1 问题定义

在零样本学习中，类别被划分为两个互不相交的集合：已见类别与未见类别。模型仅能在已见类别的样本上进行训练，而未见类别只在测试阶段出现，因此模型无法直接学习未见类别的数据分布，只能依靠类别层面的语义信息，将在已见类别上学到的音视频知识迁移到未见类别。在要求更高的广义零样本学习情景中，测试样本同时来自已见类别与未见类别的并集，模型不仅要把知识泛化到未见类别，还要保持对已见类别的判别能力，并克服分类结果向已见类别倾斜的偏置问题，因此广义零样本学习被认为更贴近真实应用。本文研究的音视频广义零样本学习（AVGZSL，Audio-Visual Generalized Zero-Shot Learning）在上述设定下同时利用视频的视觉内容与音频内容完成类别识别：视频中的动作过程与声音事件互为佐证，但二者与类别语义的关联强度随样本变化，这使得从已见类别向未见类别的知识迁移更加困难。

形式化地，记已见类别集合为 Cs\mathcal{C}_sCs​，未见类别集合为 Cu\mathcal{C}_uCu​，二者满足 Cs∩Cu=∅\mathcal{C}_s \cap \mathcal{C}_u = \emptysetCs​∩Cu​=∅。训练集由已见类别的音视频样本构成，记为 S={(xnv,xna,yn)}n=1N\mathcal{S}=\{(x_n^{v}, x_n^{a}, y_n)\}_{n=1}^{N}S={(xnv​,xna​,yn​)}n=1N​。其中，xnvx_n^{v}xnv​ 与 xnax_n^{a}xna​ 分别表示第 nnn 个训练视频的视觉流和音频流，yn∈Csy_n \in \mathcal{C}_syn​∈Cs​ 为其真实类别标签，NNN 为训练样本数量。除音视频样本外，每个类别 c∈Cs∪Cuc \in \mathcal{C}_s \cup \mathcal{C}_uc∈Cs​∪Cu​ 的类别名称及由其扩展得到的类别级文本描述均可使用：类别级语义属于零样本学习允许的侧信息，它不包含任何未见类别样本的内容。需要说明的是，在本文的归纳式设定下，训练阶段不使用未见类别的音频、视频、样本标签或任何样本级统计量。模型的目标是学习判别函数 h:(xv,xa)↦Cs∪Cuh:(x^{v}, x^{a}) \mapsto \mathcal{C}_s \cup \mathcal{C}_uh:(xv,xa)↦Cs​∪Cu​，在测试时对来自已见类别与未见类别并集的样本给出正确预测。

3.2 整体结构

**总体结构。**现有音视频广义零样本学习方法多数将类别文本嵌入直接用作最终匹配阶段的分类原型，视频编码过程与类别语义彼此割裂，本方法将经判别性优化的类别语义原型作为贯穿编码全程的条件信号，引导音频、视觉两个模态的时序证据定位与交互融合。该模型主要由三个部分组成：判别性语义原型优化模块、语义引导高斯时序定位模块和解耦模态交互与门控融合模块。首先，在类别语义构建阶段，判别性语义原型优化模块将类别名称扩展为细粒度文本描述并构建初始原型，在保持语义拓扑关系的同时增强类别可分性，解决预训练文本嵌入可分性不足、相近类别决策边界模糊的问题，为后续定位与对齐提供可靠的语义参照。其次，在时序编码阶段，语义引导高斯时序定位模块将优化后的类别语义提前注入视觉与音频序列的编码过程，并以连续高斯分布在时间轴上定位类别相关片段，解决关键证据被无关片段稀释的问题。随后，在交互融合阶段，解耦模态交互与门控融合模块把筛选后的音视频证据按模态内关系与模态间关系分开组织，并动态调节融合比例，解决直接拼接融合导致的模态干扰与模态偏置问题。最后，融合表示被投影到已见类与未见类共享的语义空间中，通过监督式对齐目标完成训练推理。

从数据流看，对于一个输入视频，我们首先将其划分为 TTT 个不重叠的连续时间片段，分别用 CLIP 图像编码器和 CLAP 音频编码器提取视觉片段特征序列与音频片段特征序列，并投影到共享维度。与此同时，每个类别的名称被扩展为面向视觉和面向听觉的文本描述集合，经CLIP、CLAP 文本编码器得到属性级语义 token 与初始类别原型；类别原型在第一阶段经判别性优化后固定。对每一个候选类别，属性级语义 token 作为键值被注入两条模态序列，使编码结果以该类别为条件；优化后的原型则作为查询，为视觉和音频分别生成多个高斯时间分布及其路由权重，得到经类别相关性加权的增强序列和紧凑的时序证据向量。增强序列随后进入模态内与模态间两条掩码注意力分支，各自的聚合 token 汇聚出模态特定关系表示与跨模态互补关系表示；动态门控依据两类关系表示、直接时序证据以及候选类别原型给出三路归一化权重，加权得到该候选类别下的融合表示。最后，融合表示被投影回原型所在的语义空间并与该类原型计算相容性分数，训练时以全部已见类别为归一化范围优化监督对齐损失，推理时在已见类与未见类的全部候选上比较经校准的分数完成预测。

SCER-AVGZSL 总体架构。对于输入视频，首先将其划分为时间对齐的连续片段，并由冻结的 CLIP 图像编码器和 CLAP 音频编码器分别提取视觉与音频序列；与此同时，候选类别的视觉描述与听觉描述经冻结的文本编码器形成属性级语义 token，并通过 DSPO 得到优化后固定的类别原型。随后，SGTG 以属性级 token 分别条件化两条模态序列，并由类别原型查询视觉与音频的独立高斯专家及路由权重，生成增强序列和直接视听证据。接着，DMIF 通过模态内与模态间两条 masked Transformer 分支组织时序关系，并结合直接证据和类别条件执行三路 Softmax 动态门控。最后，融合表示经投影头得到类别条件嵌入，并与固定原型计算归一化相容性分数；训练时仅使用已见类音视频样本并在全部 c∈Csc\in\mathcal{C}_sc∈Cs​ 上优化 Lalign\mathcal{L}_{align}Lalign​，推理时在 Cs∪Cu\mathcal{C}_s\cup\mathcal{C}_uCs​∪Cu​ 上联合比较分数，仅对已见类分数应用 calibrated stacking 后输出预测。

3.3 判别性语义原型优化

在音视频广义零样本学习中，类别文本嵌入承担着连接已见类别与未见类别的桥梁作用。CLIP、CLAP 等预训练模型产生的文本嵌入具有良好的语义关系，例如"playing guitar"与"playing violin"在语义空间中比"playing guitar"与"dog barking"更接近，这种关系正是零样本迁移的基础。然而，这些嵌入并非为当前分类任务优化：语义相近的类别原型距离过近，导致相似动作或相似声音类别难以区分；而若只追求类别间最大分离，优化又会趋向把所有原型推成彼此等距的构型，使语义相近类与语义无关类失去差别，破坏迁移所依赖的语义拓扑。为了解决这一矛盾，本文提出判别性语义原型优化（DSPO，Discriminative Semantic Prototype Optimization），在原始文本嵌入基础上学习一组新的类别原型，使其在保持原有语义邻域结构的同时获得更强的类别可分性。具体来说，该模块先由类别名称构建多粒度的初始语义表示，再以类别分离与语义保持两个互相制约的目标联合优化原型。

考虑到视觉内容与听觉内容的语义侧重不同，例如"playing piano"的视觉线索集中于手指按键的动作过程与琴键场景，而听觉线索集中于琴声的音色与节奏，我们为每个类别分别构建面向视觉与面向听觉的描述文本集合：前者由提示模板结合大语言模型生成，涵盖动作过程、主体对象与典型场景；后者涵盖声音属性、节奏音色与易混类别的听觉差异。记第 ccc 类的视觉侧描述集合为 Pcv\mathcal{P}_c^{v}Pcv​、听觉侧描述集合为 Pca\mathcal{P}_c^{a}Pca​，每个集合各含 PPP 条描述。随后，我们将两个集合分别输入已训练好的 CLIP 文本编码器与 CLAP 文本编码器，并把各条描述的嵌入按行堆叠，得到两组属性级语义 token：

3.4 语义引导高斯时序定位

长视频中并非所有片段都与类别相关：在"wood thrush calling"类视频中，关键鸟鸣可能只占整段音频的很小一部分，其余时间充斥环境噪声；"basketball dunk"的决定性扣篮动作也仅出现在局部帧段。如果按照现有范式先做与类别无关的全局编码，这些局部证据会在均匀池化中被大量冗余片段稀释；对未见类别而言，模型没有该类训练样本，更需要依靠类别语义主动搜索可能相关的时间区域。为了解决这一问题，本文提出语义引导高斯时序定位（SGTG，Semantic-Guided Gaussian Temporal Grounding），把优化后的类别语义从被动的匹配原型提升为主动的编码条件：先将属性级语义 token 注入视觉与音频序列，使编码结果以候选类别为条件；再由类别条件生成多个连续的高斯时间分布，在两条模态的时间轴上分别定位类别相关片段。该模块包括两个关键步骤：语义条件化序列编码和多高斯专家时序定位。

3.5 解耦模态交互与门控融合

真实视频中的音频与视觉并不总是强相关，画面中可能存在遮挡与无关动作，音频中可能混入背景音乐与环境噪声；不同类别对模态的依赖程度也不同，乐器演奏类需要声音与动作互相印证，而某些类别的判别信息几乎完全来自单一模态。若以无差别的全局注意力融合两条序列，跨模态注意力会把无关内容当作上下文传播，造成模态干扰；若固定偏向某一模态，又会在已见类别上形成模态偏置，损害对未见类别的泛化。为了解决这一问题，本文设计解耦模态交互与门控融合（DMIF，Decoupled Modality Interaction and Gated Fusion），通过两组互补的注意力掩码把模态内关系与模态间关系解耦为两条独立分支建模，再以样本与候选类别为条件动态调节模态内表示、跨模态表示与直接时序证据的融合比例。

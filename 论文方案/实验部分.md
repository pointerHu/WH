# 4 实验

## 4.1 实验设置

**数据集。**我们在 AVGZSL 任务广泛使用的 VGGSound-GZSLcls、UCF-GZSLcls 和 ActivityNet-GZSLcls 三个基准数据集上对本文方法进行实验评估。每个数据集的总类别数、已见类与未见类的类别数，以及两个训练阶段中各子集的类别划分情况如表 1 所示。其中，C 表示总类别数，S 表示已见类别数，U 表示未见类别数，TrS 表示训练集的已见类别数，ValS 与 ValU 分别表示验证集的已见与未见类别数，TeS 与 TeU 分别表示测试集的已见与未见类别数。

VGGSound-GZSLcls 是大规模视听数据集 VGGSound[26] 的修改版，共包含 276 个类别（138 个已见类别、138 个未见类别），类别大致涵盖动物、家庭、音乐、自然、人物、运动、工具与车辆等场景。UCF-GZSLcls 源自动作识别数据集 UCF101[27]，共 51 个类别（30 个已见类别、21 个未见类别），涵盖击剑、弹钢琴、跳水等日常活动与体育行为。ActivityNet-GZSLcls 基于 ActivityNet[28] 构建，包含 200 个日常活动类别（99 个已见类别、101 个未见类别），视频时长更长、场景更复杂，是三者中难度最高的基准。

**评价指标。**我们通过 $\mathrm{acc}_S$、$\mathrm{acc}_U$、HM 和 ZSL 四项指标评估模型在已见类与未见类上的性能。具体来说，$\mathrm{acc}_S$ 与 $\mathrm{acc}_U$ 分别表示已见类别和未见类别的平均类准确率；对于 GZSL 性能，采用二者的调和均值 HM 作为综合评价指标，HM 只有在已见类与未见类性能均衡时才能取得高值，因而能够反映模型克服已见类偏置的能力。对于 ZSL 指标，仅以未见类别子集作为候选与测试范围，报告未见类样本的平均类准确率。

**实现细节。**模型基于 PyTorch 框架实现，实验环境为 Intel(R) Core(TM) i9-14900KF CPU、128GB RAM、NVIDIA GeForce RTX 3090Ti GPU 与 Ubuntu 24.04 系统。特征提取方面，每个视频被划分为 $T=10$ 个不重叠的连续时间片段，视觉特征由冻结的 CLIP ViT-B/32 图像编码器提取（$d_v=512$），音频特征由冻结的 CLAP 音频编码器提取（$d_a=1024$），共享维度设为 $d=512$；每个类别的视觉侧与听觉侧描述各含 $P=5$ 条，分别经冻结的 CLIP 与 CLAP 文本编码器编码。第一阶段原型优化使用 Adam[29] 优化器，学习率为 1e-3，共迭代 1000 步，每步更新后将原型重新归一化到单位球面，权衡系数 $\alpha=0.5$，排序间隔 $\Delta=0.1$；收敛后原型固定。第二阶段主网络训练同样使用 Adam 优化器，权重衰减为 1e-5，批量大小为 64；高斯专家数 $E=7$，解耦交互分支层数 $L_r=2$，注意力头数为 8，温度系数 $\tau=0.05$。VGGSound-GZSLcls、UCF-GZSLcls 和 ActivityNet-GZSLcls 的初始学习率分别设置为 1e-4、7e-5 和 1e-4，训练过程中若验证 HM 分数连续 3 个 epoch 没有提高，学习率降低至原来的 0.1 倍；三个数据集分别训练 15、20、15 个 epoch。训练与评估遵循两阶段协议[3,4,5]：第一阶段在训练集上训练模型，由 ValS 与 ValU 组成的验证集用于确定校准系数 $\gamma$（网格搜索使验证 HM 最优的取值）与最佳 epoch 等参数；第二阶段使用第一阶段确定的参数，在训练集与验证集的并集上重新训练模型，并在测试集上评估得到最终结果。其余实验设置遵循 ClipClap-GZSL[4]。

**对比方法。**我们将本文方法与 5 种经典 ZSL 方法和 8 种视听 GZSL 方法进行对比。经典 ZSL 方法包括 DeViSE[30]、ALE[31]、SJE[32]、APN[33] 和 f-VAEGAN-D2[34]：其中前四者属于基于标签嵌入的判别式零样本学习方法，学习视觉特征与语义嵌入之间的相容性；f-VAEGAN-D2 属于生成式方法，通过条件生成未见类特征缓解样本缺失问题。为适配视听任务，上述 ZSL 基线均以音频与视觉特征共同作为输入。视听 GZSL 对比方法包括 CJME[1]、AVGZSLNet[2]、AVCA[3]、TCaF[5]、Hyper-multiple[10]、KDA[11]、ClipClap-GZSL[4] 和 EZ-AVGZL[8]：其中 CJME 与 AVGZSLNet 通过共享嵌入空间实现多模态对齐；AVCA 与 TCaF 基于注意力机制显式建模跨模态与时序交互；Hyper-multiple 引入双曲几何刻画类别层级结构；KDA 利用大语言模型生成的细粒度描述增强语义嵌入；ClipClap-GZSL 与 EZ-AVGZL 侧重利用预训练大模型特征与音视频-文本对齐实现高效识别。对于能够在统一输入设置下复现的基线，本文采用与本文一致的 CLIP/CLAP 输入特征与文本嵌入；表 2 中除 EZ-AVGZL 外的对比结果依据 KA-GZSL 实验部分在相同基准上的汇总结果补充。由于 KA-GZSL 未报告 EZ-AVGZL 在该统一特征设置下的复现结果，EZ-AVGZL 一行采用其原论文公开结果并以 † 标记，该行主要用于横向参考，不参与严格同设置下的公平性结论。

从表 2 可以看出，本文方法在三个数据集上均取得了更高的 GZSL 调和均值，说明模型在已见类识别能力与未见类泛化能力之间实现了更好的平衡。具体而言，在 UCF-GZSLcls 上，本文方法取得 61.28% 的 HM；若按表中全部结果横向比较，相较 EZ-AVGZL 的 58.24% 提升 3.04 个百分点，而在统一 CLIP/CLAP 设置的基线中，相较 ClipClap-GZSL 的 55.13% 提升 6.15 个百分点。在 ActivityNet-GZSLcls 上，本文方法的 HM 达到 31.44%，较 ClipClap-GZSL 的 27.11% 提升 4.33 个百分点；在 VGGSound-GZSLcls 上，本文方法取得 17.62% 的 HM，同样高于 ClipClap-GZSL 的 15.73%，提升 1.89 个百分点。上述结果表明，本文方法的优势并非依赖单侧提高已见类或未见类准确率，而是来自两者的协同改善。

在 ZSL 性能方面，本文方法在 VGGSound-GZSLcls、UCF-GZSLcls 和 ActivityNet-GZSLcls 上分别取得 12.89%、51.74% 和 25.21% 的准确率。其中，VGGSound-GZSLcls 与 ActivityNet-GZSLcls 上的结果高于表中对比方法；UCF-GZSLcls 上的 ZSL 略低于 KDA 的 52.66%，但同时获得了更高的 S、U 与 HM，说明本文方法没有通过过度偏向未见类来换取单一 ZSL 指标，而是在 GZSL 场景中取得了更均衡的总体性能。

上述优势主要来源于两方面。其一，语义引导高斯时序定位使模型在编码阶段即以类别语义为条件聚焦关键片段，未见类别的判别证据不再被冗余片段稀释，这直接反映在 $\mathrm{acc}_U$ 与 ZSL 指标的提升上；其二，判别性原型与类别条件门控共同保证了已见类与未见类分数的可比性，使 HM 在两侧性能之间取得更好的平衡。此外，与规模较小、场景聚焦的 UCF-GZSLcls 相比，VGGSound-GZSLcls 与 ActivityNet-GZSLcls 包含更多类别、更复杂的场景与更明显的视听弱关联现象，任务难度更高；本文方法在这两个更具挑战性的数据集上仍取得了领先的 HM 结果，说明时序证据定位与动态融合机制在复杂场景下的作用更为显著。

| **$(1-\alpha)\mathcal{L}_{rank}+\alpha\mathcal{L}_{sep}$** | **17.62**     | **12.89** | **61.28** | **51.74** | **31.44**        | **25.21** |

结果显示，仅追求类别分离虽然能够提高类别间的判别性，并使 HM 相较初始原型略有改善，但三个数据集的 ZSL 均出现下降，说明语义拓扑被破坏后未见类迁移受损；仅保持语义排序结构时，ZSL 恢复并继续提升，但原型可分性仍不足，HM 仍低于联合目标；二者联合优化在全部数据集上取得最佳平衡，验证了“判别性与语义保持缺一不可”的设计动机。

**DMIF 分支与门控消融。**我们对解耦交互与门控融合的内部结构进行消融：仅保留模态内分支、仅保留模态间分支、移除直接证据分支（门控退化为二路）、以平均融合替代门控（三路等权），以及完整的三路门控。实验结果如表 7 所示。

| -------------------------- | ------------------- | --------------- | --------------- | --------------- | ---------------------- | --------------- |
| 仅模态内分支               | 15.86               | 11.39           | 56.94           | 47.92           | 28.24                  | 22.44           |

可以看出，单独使用任一分支的性能均低于双分支组合，说明模态内稳定线索与跨模态互补信息各有不可替代的作用；移除直接证据分支或以等权平均替代门控均导致性能下降，其中完整三路门控相较平均融合在三个数据集上的 HM 分别提高 1.13、2.40 和 1.77 个百分点，表明按样本与候选类别自适应调节三路信息的比例，对于抑制模态噪声、克服模态偏置具有实际贡献。

**文本编码器消融。**本文分别利用 CLIP 与 CLAP 文本编码器编码视觉侧与听觉侧描述。为验证双文本编码器的作用，我们设置仅使用 CLIP、仅使用 CLAP 以及同时使用两者三种方案（单编码器方案中，属性级语义 token 与初始原型均只来自对应编码器）。实验结果如表 8 所示。

## 4.4 定性分析

**t-SNE 可视化。**为了从特征分布维度验证本文方法的有效性，我们利用 t-SNE[35] 对模型的输入特征与输出嵌入进行可视化对比。图 3 展示了三个数据集上若干已见与未见类别的音频输入特征、视觉输入特征以及本文方法学习得到的类别条件嵌入。可以观察到，原始音频与视觉特征在特征空间中的分布较为分散、类别边界模糊；经本文模型学习后的嵌入呈现出紧凑且清晰可分的聚类，且未见类别的簇与已见类别的簇分离良好，各类别的原型均位于对应样本簇的内部。上述结果表明，本文方法能够将音视频输入有效映射到与类别语义一致的判别空间中，并将该能力泛化至未见类别。

**高斯时序定位可视化。**为验证 SGTG 能否准确定位类别相关的时序证据，我们在图 4 中展示了若干测试样本的高斯软掩码沿时间轴的分布，并与对应的视频帧和音频频谱对齐呈现。可以观察到：对于未见类别样本，尽管模型从未接触过该类的任何训练数据，混合高斯权重仍然集中于类别语义所指示的关键时间段（如鸟鸣出现的片段、扣篮动作发生的帧段），而背景与静音片段的权重被显著压低，直观证明了以可迁移语义原型为条件的定位能力；对于声音先于画面（或画面先于声音）出现的样本，音频高斯中心与视觉高斯中心分别聚焦于不同时刻，体现了双模态独立定位对视听异步现象的适应能力。此外，以错误类别为条件时，高斯权重分布趋于弥散且相容性分数明显降低，与式（30）"类别条件下证据存在性"的判别机制相印证。

**门控权重分析。**图 5 统计了不同类别样本在三路门控上的平均权重分布。可以观察到，以声音事件为主要判别依据的类别（如动物鸣叫类）在模态内分支与直接证据分支上获得更高权重，而需要声画互相印证的类别（如乐器演奏类）则更依赖模态间分支；同一类别下，含噪样本的跨模态权重低于干净样本。这一现象说明门控机制确实学习到了随样本与类别语义变化的融合策略，而非退化为固定配比。

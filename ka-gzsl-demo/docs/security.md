# 部署、隐私和安全边界

本项目首先面向 VOA285C 的**本机论文演示**。不是可以直接暴露到公网的生产视频解析服务。

## 默认保护

只监听 `127.0.0.1:8765`，限制 Host，POST 需要同源页面拿到的随机进程令牌，不开放跨域 CORS。上传扩展名受限，实际格式由 FFprobe 验证；默认最大100MB、120秒、4096像素边长。文件以服务器 UUID 命名，不信任用户文件名，不使用 shell 拼接执行命令。

应用最多接受一项运行与一项排队任务；GPU 工作在隔离进程串行执行。FFprobe、FFmpeg 和整个推理进程有时限。模型缺失、无音轨、无法解码、维度不符会明确失败，不回退到伪造特征。

## 模型文件信任

旧 PyTorch 1.7.1 的 `torch.load` 不能使用现代 `weights_only` 防护，pickle 反序列化可执行代码。**只加载研究者主动安装、来源可信的本地权重**。网页不接受用户上传模型、pickle、NPZ 等作为可执行模型资源。应用只对管理员离线导出的模型与固定示例 NPZ 操作。

独立模型环境使用历史依赖，是复现实验兼容性选择，不是安全升级。不要把该旧环境直接用作公网应用服务器。独立 Python>=3.10 Web 环境仍需定期维护依赖。

## 本地中间文件

`runtime/jobs/` 保存用户视频、解码音轨、中间特征与结果，默认保留24小时。清理在服务启动/提交任务时进行；不是一个独立的定时守护程序。服务停止且无新任务时，不会自动删除到期文件。可在确认无活动任务后手动清理本项目的 `runtime/jobs`。

这些内容被 `.gitignore` 排除，代码没有把输入视频、音频或实验日志上传云端的功能。WH 是公开仓库，因此只上传去标识化验证清单和非私密示例结果。

## 公网或局域网展示前

不要只把 host 改成 `0.0.0.0` 就认为安全。需另外加入身份认证、HTTPS 反向代理、代理层请求大小限制、用户隔离和磁盘配额、解析进程容器/沙箱、依赖安全更新、任务取消与日志保留策略。未设置远程端口映射，也未修改用户系统防火墙。
